## Contract and design

Product schema version **1.0** includes event/request/evaluation/decision IDs,
UTC timestamp, stored sequence, trusted principal/agent/context, trusted policy
and tool classification, argument hash, actual outcome/reasons, envelope/recovery
stage, effective gate, CDE signal projection, actual evidence/lease requirements,
lease identity/check/epoch/expiry. Unavailable facts are null; reason arrays are
always arrays. No raw arguments, credentials, lease tokens or user text enter the
product stream. Tool ID is the existing action identity.

Vocabulary: `authentication.rejected`, `cde.signal.created`,
`authority.requested`, `authority.decision`, `authority.contracted`,
`authority.restored`, `recovery.stage_changed`, `lease.issued`, `lease.rejected`,
`lease.revoked`, `capability.revoked`, `lease.epoch_advanced`, `review.requested`,
and `tool.enforcement.allowed`, `.denied`, `.review`, `.failed`.
Nonce versus legacy token revocation uses distinct reason codes; capability and
epoch operations have distinct event types. No fake review resolution or successful
execution event exists.

HTTP assigns request UUIDs and returns them in a header; body-supplied correlation
and principal fields have no effect. CDE's selected event ID and a server decision
UUID correlate the tool chain. Trusted direct callers can supply an optional audit
context. `authority.getEventsForRequest(requestId)` returns detached, ordered
records. The audit README includes direct runtime and SQLite-reader examples.

SQLite schema **3** migrates validated v2 stores without rewriting governance
state; v1 migrates through v2. The event table is separate, append-only via normal
APIs and guarded against SQL update/delete. Unique UUIDs identify events; committed
sequence orders them independently of timestamps. Migration starts an empty audit
history rather than fabricating events for prior state.

Authority decisions, consumed evaluation IDs and contraction/restoration events
commit together. Issuance, nonce/legacy/capability revocation and epoch advancement
each commit with their required event. Any append failure rolls back the state
operation. Enforcement records commit separately before the gateway's normal
response. Query availability is not required for decisions or writes. Requests
already being refused retain that refusal even when their best-effort failure
event cannot be written.

## Compatibility qualification and remaining limits

No separately named Paper 9 canonical schema/writer exists in this checkout. The
available frozen 32-event records, existing CDE JSONL writer, frozen authority
oracle and legacy gateway record shape remain unchanged and tested. This does not
claim certification against an absent Paper 9 artifact.

The stream is not cryptographically tamper-evident. A hostile database owner can
alter schema/files or restore an older database. Migrated pre-audit history cannot
be reconstructed. Crashes between decision and enforcement may leave an incomplete
chain; transport failure after commit does not imply rollback or exactly-once
issuance. Failed audit persistence cannot reliably record its own failure.
Default memory storage loses events on restart; durability requires injecting the
existing SQLite store. Query APIs are trusted in-process only. CDE `/turn` remains
evaluation-only, outside the governed tool lifecycle. Full-history integrity scans
are appropriate to the current small evaluator, not a large analytics workload.
